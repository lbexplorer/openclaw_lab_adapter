# 项目范围说明

这个项目用于实验室环境下的 OpenClaw 适配开发，和 `openclaw` 主仓库保持松耦合。

## 适合放在这里的内容

- 实验室硬件专属配置
- 针对特定底盘/导航栈的桥接脚本
- 非通用的 waypoint 配置
- 调试脚本、验证脚本、硬件说明
- 还不稳定、仍在快速迭代的 skills

## 不建议直接耦合到 openclaw 的内容

- 依赖实验室特定路径的脚本
- 依赖特定底盘型号的控制逻辑
- 依赖特定 ROS1 工作空间的服务定义
- 暂未稳定的硬件接口协议

## 当前默认假设

- 平台优先按 Scout 风格设计
- 当前底层仍保留 ROS1
- 第一阶段只覆盖移动与导航
- 感知、跟踪、机械臂后续按真实硬件再拆
