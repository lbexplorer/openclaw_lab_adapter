## 2026-05-07 -统一skills协议
- 开发主线：按 “技能接口标准化 → 关键技能补齐 → 智能体闭环编排” 的顺序推进项目开发。智能体本身只能调用已有能力，如果底层 skill 不完整，Agent 再复杂也只能停留在“会说但不会做”。而 sailors_onboard-main 本身已经有比较完整的 ROS1 车端基础，包括感知、底盘/传感器驱动、ROS Navigation/Gmapping、ROS 与 FastDDS 桥接等能力，所以更合理的路线是：先把这些能力包装成稳定 skills，再让智能体做任务分解、调用和结果反馈。

- 问题描述：当前skils虽然测试成功，在测试的时候发现agent虽然调用skills，但是没有显示skills调用是否成功，没有接受到skills的反馈，因此需要完善 agent 执行反馈机制，让 agent 不只显示“指令下发成功”，而是读取 skill result 并反馈真实执行状态。此外还需要统一skills协议，不然后续的开发没有一个统一的规范
1：统一 skill 协议
目标：
- 所有 skill 都有统一输入输出；
- skill 可以返回执行状态；
- Agent 可以读取 skill result；
- 支持同步 skill 和异步 skill。
